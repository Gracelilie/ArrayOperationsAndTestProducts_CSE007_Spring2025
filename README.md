## Description
This project contains two Java programs focusing on **arrays, object-oriented programming, and basic data handling**.

1. **ArrayOperations.java**  
   Performs operations on arrays such as calculating sum, average, maximum, and minimum values.  
   Reinforces loops, indexing, and array traversal while validating user inputs and displaying formatted results.

2. **TestProducts.java**  
   Tests a `Product` class by creating multiple product objects and displaying their properties such as name, price, and ID.  
   Demonstrates constructor use, getter/setter methods, and object management in Java.

---

##  Real-World Application
**ArrayOperations.java:**  
Simulates how software handles data analytics tasks such as summarizing sales, temperature, or sensor data. The same logic applies in tools like Excel or Python’s NumPy when calculating averages and trends.

**TestProducts.java:**  
Models how real e-commerce or inventory systems manage product data — each product as an object with properties like name, price, and ID. Reflects the structure behind apps like Amazon or retail management software.

Together, both programs illustrate how Java is used in **data processing** and **object-oriented modeling** in professional applications.
